# 10.1 做功与电势能 · 可交互课件

高中物理（人教版必修第三册）10.1 节「做功与电势能」的交互可视化课件，共 **18 步**，两幕结构：

- **第一幕 · 做功与路径无关**：直线 / 折线 / 任意曲线三条路径并排比对，曲线用微元法「曲化直」切成 N 段（N=1~32 可调），每小段拆成「沿场线的一步」+「横穿的一步（不做功）」。
- **第二幕 · 电势能的可视化**：把电势画成一张有高低的地形面（暖红 = φ>0，冷蓝 = φ<0），球贴在面上（轴上位置 = ±φ），球的大小 = |q|，金色高度尺量出 Ep = qφ。
